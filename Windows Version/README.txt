SpriteSheet Assembler 1.0 — source-image drag-and-drop edition\n\nRun start_windows.bat. The launcher installs Pillow and tkinterdnd2 if missing (internet needed only for installation). Drag one or multiple image files from Windows Explorer into SOURCE IMAGES. Select a source and click grid cells to place it. Default cell size: 512x512. Export PNG from the toolbar. Everything is processed locally.\n
